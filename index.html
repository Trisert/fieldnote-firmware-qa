Start with the uncomfortable part: make the missing proof visible, assign it, and keep the decision in the project history.

The starter kit is deliberately process-light. It gives a small team enough structure to stop losing context.

Seven files. One repeatable loop.

The bundle is not a course and it is not a certification package. It is a set of working surfaces for the next firmware project.
